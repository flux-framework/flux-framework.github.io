# Release Notes

flux-pmix version 0.9.0 - 2026-11-04
------------------------------------

## New Features

 * plugin: share the node topology with clients ([#157](https://github.com/flux-framework/flux-pmix/issues/157))
 * plugin: avoid deadlock on log upcall error path ([#158](https://github.com/flux-framework/flux-pmix/issues/158))
 * plugin: implement server callback for `PMIx_Log()` ([#156](https://github.com/flux-framework/flux-pmix/issues/156))
 * add a wire protocol capture shim and wireshark dissector ([#150](https://github.com/flux-framework/flux-pmix/issues/150))

## Fixes

 * plugin: abort if runtime major version differs from build time ([#164](https://github.com/flux-framework/flux-pmix/issues/164))
 * plugin: fix occasional MPICH `MPI_Init()` failure with "fence over proc
   subset is not supported" ([#161](https://github.com/flux-framework/flux-pmix/issues/161))
 * plugin: offer only pmix.auth=native by default ([#159](https://github.com/flux-framework/flux-pmix/issues/159))
 * plugin: improve compliance with the PMIx Standard ([#154](https://github.com/flux-framework/flux-pmix/issues/154))
