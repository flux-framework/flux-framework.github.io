# Release Notes

flux-core version 0.91.0 - 2026-11-03
-------------------------------------

## New Features

 * jobtap: add `flux_jobtap_dependency_check ()` for checking a dependency
   in a job ([#7877](https://github.com/flux-framework/flux-core/issues/7877))
 * shell: add support for PMI-1.2 and group barriers ([#7862](https://github.com/flux-framework/flux-core/issues/7862))
 * shell: factor out PMI kvs for use by other process managers ([#7856](https://github.com/flux-framework/flux-core/issues/7856))
 * support queue membership by hostlist ([#7846](https://github.com/flux-framework/flux-core/issues/7846))
 * python: add `parse_timestamp()` ([#7853](https://github.com/flux-framework/flux-core/issues/7853))
 * python: parse ISO 8601 basic format dates in `parse_datetime` ([#7850](https://github.com/flux-framework/flux-core/issues/7850))
 * sdexec: kill non-waitable units at module teardown ([#7848](https://github.com/flux-framework/flux-core/issues/7848))
 * Move counts from libjob into separate libresourcecount ([#7841](https://github.com/flux-framework/flux-core/issues/7841))
 * sdexec: move the broker rank in unit names ([#7845](https://github.com/flux-framework/flux-core/issues/7845))
 * flux-top: get queue conf from job manager ([#7843](https://github.com/flux-framework/flux-core/issues/7843))

## Fixes

 * broker: stop shutdown timer on entry to FINALIZE ([#7891](https://github.com/flux-framework/flux-core/issues/7891))
 * libresourcecount: validate min for '^' operator and add
   `libresourcecount_bounded_last ()` ([#7889](https://github.com/flux-framework/flux-core/issues/7889))
 * libsubprocess: check error paths ([#7743](https://github.com/flux-framework/flux-core/issues/7743))
 * shell: set `HWLOC_THISSYSTEM=1` with `hwloc.xmlfile` ([#7890](https://github.com/flux-framework/flux-core/issues/7890))
 * job-manager: avoid posting redundant and failing dependency events ([#7885](https://github.com/flux-framework/flux-core/issues/7885))
 * job-manager: do not drop events when one fails to apply ([#7881](https://github.com/flux-framework/flux-core/issues/7881))
 * job-list: fix NULL dereference on unlikely error path ([#7883](https://github.com/flux-framework/flux-core/issues/7883))
 * sched-backfill: handle a permanently blocked head job due to down or
   drained nodes ([#7869](https://github.com/flux-framework/flux-core/issues/7869))
 * resource: fix shrink when acquire precedes resource-define ([#7851](https://github.com/flux-framework/flux-core/issues/7851))
 * shell: get instance owner from the IMP, and   drop `FLUX_*` from IMP
   config examples ([#7849](https://github.com/flux-framework/flux-core/issues/7849))
 * add minor guest restrictions ([#7844](https://github.com/flux-framework/flux-core/issues/7844))
 * sdbus: conform to RFC 52 ([#7839](https://github.com/flux-framework/flux-core/issues/7839))
 * job-manager: implement config rollback on reload failure  ([#7838](https://github.com/flux-framework/flux-core/issues/7838))

## Performance

 * fix quadradic time slowdowns on restart with many pending jobs ([#7874](https://github.com/flux-framework/flux-core/issues/7874))
 * let some reactor loops ingest more than one message per iteration ([#7875](https://github.com/flux-framework/flux-core/issues/7875))
 * python: simple efficiency improvements for `flux jobs` ([#7876](https://github.com/flux-framework/flux-core/issues/7876))
